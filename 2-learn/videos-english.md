# Videos in English: learn from zero

Full courses that build each concept from scratch, with no exam tricks. Once a topic clicks, practise it with the [videos for solving past questions](../3-practice/videos-pyq-solving.md).

> **Best structured foundation overall = [Khan Academy](https://www.khanacademy.org/math)**
> (free, exercises + hints, exactly high-school level). YouTube full-courses below
> are better for one-sitting binge learning. Use both: Khan to practice, these to learn.

## Concept dependency order (do earlier ones first)

`Algebra → Trigonometry/Precalculus → Coordinate & Conic → Calculus`
Arithmetic, P&C, Probability and Number System can be done in any order. Skip Vectors: they are off the syllabus.
